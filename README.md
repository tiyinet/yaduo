# 芽朵酒店管理系统

面向酒店、民宿与多业态住宿的一体化经营管理平台 —— 一套系统、三大板块、四端全覆盖。

## 三大板块
- **PMS · 酒店经营管理系统**：房态房价日历、全渠道订单、入住退房夜审、财务报表
- **CMS · 酒店内部管理系统**：排班考勤、保洁维修、采购库存布草、运营日报
- **MKT · 酒店营销推广管理系统**：会员储值积分、优惠券活动、OTA 直连、尾房临工跨店互助

## 四端全覆盖
手机端（微信小程序）· 微信端（H5）· 电脑端（PC 后台）· 桌面端（Windows 客户端）
