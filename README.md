## 核心功能详解

### 智能房态管理

可视化房态图实时展示每间房的状态，支持日视图、月视图切换，房态颜色可自定义。

- 可视化房态图，房间状态一目了然
- 日视图 / 月视图切换，满足不同操作习惯
- 快速入住、快速退房，3 步完成办理
- 客房清洁任务自动派发，保洁进度实时跟踪
- 多种房态类型，颜色自定义

### 全渠道订单管理

支持美团、携程等渠道订单自动同步统一管理，待确认、已确认、已入住、已完成、已取消全程跟踪，不漏单、不重单，避免超售。

- 美团 / 携程渠道直连，订单自动同步
- 订单状态全程跟踪，操作留痕可追溯
- 批量确认 / 取消订单，提升效率
- 订单备注、特殊需求不遗漏
- 订单数据统计分析，客源结构一目了然

### 客户会员体系与营销工具

会员等级、积分、储值、优惠券多重激励；限时特惠、连住优惠、新客立减等营销活动一键创建。

- 会员等级体系，积分 / 储值 / 优惠券
- 营销活动一键创建
- 客户标签管理，精准营销触达
- 客户评价收集，口碑管理
- 营销效果数据分析，投入产出比一目了然

### 财务自动对账

财务报表自动生成，多渠道自动对账，夜审自动化，经营数据实时可视。

- 营收统计、账单管理
- 多渠道对账，告别手工核对
- 夜审自动化，交接班有据可查
- 经营数据多维度汇总

### 内勤管理 CMS（12 大功能）

日报、保洁、维修、交接、排班、考勤、投诉、门锁、布草、员工、物品、采购，12 大内勤功能全覆盖。

- 运营日报，每日经营数据自动汇总
- 客房保洁任务派发，进度实时跟踪
- 工程维修工单管理，维修记录可追溯
- 员工排班 / 考勤，人事管理轻松搞定
- 布草 / 物品 / 采购管理，库存不浪费

### 营销数据分析

实时经营数据、入住率分析、客源分析、房型分析，多维度报表帮老板做对决策，手机端随时查看。

## 独创功能：芽朵联盟

全国 10000+ 酒店加入芽朵联盟，单体酒店也能用上集团化资源。

- **尾房抢单**：有空房发布到联盟，周边酒店客满时抢单推荐，空房不再浪费，提升入住率
- **临工抢工**：旺季缺人手，发布临工需求，周边酒店闲置员工抢工帮忙，2 小时平均响应
- **满房互助**：自家满房时把客人导给联盟酒店，订单不流失，还能拿分成
- **联盟社群**：酒店老板、前台、保洁、维修各岗位交流圈，经验分享、问题求助、资源对接

## 安装说明（Windows 客户端）

1. 到 [Releases](../../releases) 页面，下载 `YaduoHotel-Setup-2.0.exe`（安装版）或 `YaduoHotel-Setup.zip`（压缩包）
2. 压缩包请先解压，**不要直接在压缩包里双击运行**
3. 双击 `YaduoHotel-Setup-2.0.exe` 开始安装
4. 若 Windows 弹出蓝色提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。这是安装包未购买代码签名证书时的常规提示，不是病毒；本软件不捆绑任何第三方软件
5. 若电脑装过旧版，先彻底退出旧版（含右下角托盘图标：右键 → 退出），再安装，避免新旧文件混在一起
6. 安装完成后，桌面与开始菜单会出现「芽朵」图标，双击使用

> 首次登录需用官网注册的账号；客户端的房态、订单数据与小程序 / H5 / 网页后台同源实时同步。

## 常见问题

**Q：必须装客户端才能用吗？**
不是。小程序、H5、PC 网页后台都能用。客户端是给前台和财务做高强度操作用的，房态订单报表同屏，效率更高。

**Q：数据放在哪？安全吗？**
云端加密存储，自动备份，权限管理 + 操作日志。多端同一套数据，换设备不用迁移。

**Q：能对接美团、携程吗？**
支持渠道订单自动同步，避免超售和漏单。

**Q：只有几间房，免费版够用吗？**
10 间客房以内基本够用。超过可升级订阅版，99 元/月起。

**Q：多家店能一起管吗？**
支持多分店管理，统一会员、统一报表，各店数据独立又汇总。
